# Sokolovskaya Beauty — лендинг 2.0

Современная, продающая версия сайта студии наращивания и окрашивания волос
(г. Калининград). Переработанная версия оригинального Tilda-сайта: новая
структура, акцент на конверсию, премиальный визуал.

## Что внутри

- `index.html` — разметка лендинга (все секции)
- `styles.css` — дизайн-система, адаптив, анимации
- `script.js` — интерактив (меню, счётчики, табы цен, FAQ, форма)

## Секции (порядок выстроен по CRO-воронке)

Внимание → доверие → ценность → снятие возражений → запрос:

1. **Бегущая строка** с ключевыми офферами
2. **Hero** — оффер + статистика с анимированными счётчиками + подарок
3. **Строка доверия** (4.9★, 214 отзывов, площадки, гарантия) — proof above the fold
4. **Преимущества** (незаметное крепление, без неудобств, сопровождение, поставщики)
5. **Истории клиентов** (Оля, Вика, Саша) — формат «до/после» через эмоции
6. **6 причин выбрать студию**
7. **Как всё проходит** — 4 шага (снятие возражений)
8. **Команда** с раскрывающимися блоками образования
9. **Отзывы** — именованные, с оценками и площадками (Яндекс/2ГИС/Instagram)
10. **Прайс-лист** с переключаемыми вкладками
11. **FAQ** — аккордеон
12. **Форма записи** — честная срочность, гарантия, proof рядом с кнопкой, валидация и маска телефона
13. **Футер** с контактами и соцсетями

## SEO

- `index.html` содержит JSON-LD (`HairSalon` + `OfferCatalog` + `FAQPage`), canonical, Open Graph/Twitter, гео-мета
- `robots.txt` и `sitemap.xml` в корне
- `role="img"` + `aria-label` на фоновых фото для доступности и индексации

**Перед запуском замените плейсхолдеры:** домен `sokolovskaya-beauty.ru`, координаты,
ссылки соцсетей (`sameAs`), число отзывов и рейтинг — на актуальные данные из Google Business Profile.

## Запуск

Просто откройте `index.html` в браузере. Локальный сервер не требуется,
но для корректной загрузки шрифтов/фото нужен интернет.

```bash
open index.html
```

## Что улучшено относительно оригинала

- Единая премиальная дизайн-система (тёплая медно-бежевая палитра, элегантная типографика Cormorant + Manrope)
- Чёткая воронка: оффер → доверие → истории → причины → команда → цены → FAQ → запись
- Усиленные продающие формулировки и явные CTA на каждом экране
- Анимации появления, счётчики, плавающая кнопка записи, липкая шапка
- Полная адаптивность (мобильное меню, перестроение сеток)
- Рабочая форма заявки с валидацией и маской телефона (готова к подключению к CRM)

## Подключение заявок к CRM

В `script.js`, в обработчике `form submit` (комментарий
«Здесь можно отправить данные на сервер / в CRM»), добавьте `fetch()`
к вашему backend / Tilda Forms / amoCRM / Telegram-боту.

## Замена фотографий

Сейчас используются временные фото с Unsplash. Замените `background-image`
в `.case__media` и `.member__photo` на работы и фото мастеров студии.
